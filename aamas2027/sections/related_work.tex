\section{Related Work}
\label{sec:related-work}
\paragraph{Planning and dependency representations.}
ReAct interleaves reasoning, actions, and observations~\cite{yao2023react}. ToolPlanner methods support task execution over large tool collections~\cite{wu2024toolplanner,liu2025toolplanner}, while LLM+P and Generalised BDI Planning introduce explicit planning and goal management~\cite{liu2023llmp,meneguzzi2025bdi}. GeoAgent and Earth-Agent apply multistep planning and execution to geoscientific analysis~\cite{chen2024geoagent,feng2026earthagent}. SciToolAgent orchestrates scientific tools through a knowledge graph~\cite{ding2025scitoolagent}; HyperAgent constructs a tool hypergraph from input/output schemas and searches for supporting tools~\cite{zhai2026hyperagent}. AgentGS instead represents shared operations as Capabilities and strategies as Skills. It preserves each operation's dependencies and usage constraints within its source strategy, allowing local cross-strategy reuse before tool selection.

\paragraph{Geoscientific evaluation.}
GeoBench and EarthSE evaluate knowledge understanding and scientific exploration without requiring actual tool calls~\cite{deng2023k2,xu2025earthse}. Scientific agents demonstrate execution of code and data-processing tasks~\cite{ding2025scitoolagent,chen2024geoagent,feng2026earthagent}. More recent benchmarks explicitly examine orchestration: GeoBenchX evaluates multistage geospatial tasks against reference solutions~\cite{krechetova2025geobenchx}; Earth-Bench distinguishes autonomous planning from instruction following and records tool inputs and outputs~\cite{feng2026earthagent}; GeoAgentBench checks invocation order, parameters, and map artifacts in a GIS sandbox~\cite{yu2026geoagentbench}; and GeoNatureAgent Benchmark tests multitool analysis and error recovery with real APIs~\cite{diazireland2026geonatureagent}. GeoToolEval extends evaluation across ten research themes and supports analysis of operation selection, dependencies, composition, artifact consumption, and final answers within the same task. It also examines completion of necessary operations, helping distinguish missing-capability failures from execution errors.
